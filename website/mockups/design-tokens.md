# SheperD design tokens

## Color

| Token | Value | Use |
| --- | --- | --- |
| Midnight navy | `#061220` | Hero, footer, pilot form field. |
| Dark teal | `#0B2B32` | One narrative process band. |
| Paper | `#F7F8F5` | Primary content surface and artifacts. |
| Ice | `#EAF2F7` | Evidence and trust sections. |
| Cobalt | `#2167F3` | CTA, active state, route, highlighted line. |
| Electric azure | `#70B8FF` | Route line, metadata on dark. |
| Conditional amber | `#D69A45` | Missing evidence and conditional review only. |
| Hairline blue-gray | `#C6D5DF` | Borders, separators, ruled records. |

Rules: no gradient text, no neon decoration, no purple/pink/rainbow gradients, no glassmorphism, no excessive shadows, no decorative rounded-card grid.

## Type

- Display serif: Baskerville / Georgia / Iowan Old Style fallback.
- Body sans: neutral system sans, 16–18px body range.
- Metadata: monospace, 9–11px, uppercase tracking.
- Hero desktop: 64–104px, compact line-height, generous negative space.
- Section headings: 50–82px desktop; 50–60px mobile.
- Body measure: approximately 52–62 characters per line.

## Layout

- Desktop content width: 1,180px inside a 1,440px canvas.
- Section rhythm: 86px desktop; 46–74px mobile.
- Desktop section canvas: 1,440 × 1,024.
- Mobile section canvas: 390 × 844.
- Responsive checks: 320, 375, 768, 1,440, 1,920px.
- One primary surface per section; borders before shadows.
- CTA pill radius: 999px. Artifact corners: square or restrained 0–8px radius.

## Visual grammar

- Persistent route: thin electric-blue line, dashed only where the record is being traced.
- Artifact labels: `ILLUSTRATIVE ARTIFACT · SYNTHETIC RECORD · NOT CUSTOMER DATA`.
- Route endpoint: `HUMAN REVIEW BOUNDARY` before `Potential credit or refund`.
- Amber means missing or conditional evidence; never success.
- Imagery: original generated material studies only; no stock, logos, people, or customer scenes.
