# SheperD visual tokens

## Palette

| Token | Value | Use |
| --- | --- | --- |
| Midnight navy | #061220 | Hero, closing CTA, form |
| Dark teal | #0B2B32 | Recovery-path narrative band |
| Paper | #F7F8F5 | Editorial content sections |
| Ice | #EAF2F7 | Evidence and outcome sections |
| Cobalt | #2167F3 | CTA, route, active state |
| Electric azure | #70B8FF | Route line and dark-section metadata |
| Conditional amber | #D69A45 | Missing or conditional evidence only |
| Hairline blue-gray | #C6D5DF | Dividers and record boundaries |

## Type

- Display: Georgia or an approved local high-contrast serif fallback.
- Body: system sans.
- Metadata: system monospace.
- One display family, one body family, one metadata family.

## Composition

- Compound-inspired landing-page rhythm: announcement, nav, centered promise, visual proof, capability sequence, comparison, success definition, CTA.
- SheperD-specific visual world: container terminal film, evidence records, cobalt route, human-review boundary.
- Shape system: sharp editorial panels; pills only for CTAs and compact controls.
- Motion concept: the route draws and pauses at human review. Reduced-motion output is static.
