These assets were generated through the existing Creative Production board as art-direction comps. They are intentionally separate from the deterministic UI exports so the native visual treatment can be reviewed on its own.

## Section exports

Each direction contains desktop and mobile PNGs for the hero, proof strip, problem, recovery path, evidence, pilot scope, trust/FAQ, success definition, closing CTA, and pilot form.

## Responsive exports

Both directions include rendered assemblies at 320, 375, 768, 1440, and 1920 pixels.

## Source and boundaries

The deterministic renderer reuses the original SheperD container artwork from the v2 pack. Compound Planning informed the information architecture and pacing only. SheperD copy, typography, artwork, records, and brand expression remain original.
