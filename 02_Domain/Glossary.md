# Glossary

| Term | Working definition |
|---|---|
| AFA | “AI Freight Audit,” used in company positioning; canonical meaning and scope need approval. |
| BCO | Beneficial cargo owner. |
| Charge Complaint | FMC process for information about potentially non-compliant common-carrier charges under 46 U.S.C. §41310. |
| D&D | Demurrage and detention. |
| Demurrage | Charge tied to cargo remaining in terminal space beyond free time. |
| Detention | Charge tied to equipment remaining outside the terminal beyond free time. |
| FMC | U.S. Federal Maritime Commission. |
| Free time | Period before D&D begins accruing under applicable rules/terms. |
| MTO | Marine terminal operator. |
| NVOCC | Non-vessel-operating common carrier. |
| OSRA 2022 | Ocean Shipping Reform Act of 2022, enacted 2022-06-16. |
| RaaS | Used publicly as “Refund As A Service”; “Revenue As a Service” also appears and should not be used interchangeably. |
| Reparations | Remedy for actual injury through an eligible FMC complaint; not equivalent to an automatic refund. |
| VOCC | Vessel-operating common carrier. |

See [[02_Domain/D&D and OSRA Primer]] for operational nuance.
